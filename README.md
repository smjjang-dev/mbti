# 별빛 신전 — 내 안의 작은 신은?

초등학생과 중학생을 위한 모바일 중심 성격 이야기 테스트입니다. 12개의 학교생활 질문에 답하면 MBTI 네 글자에 연결된 16명의 창작 신 중 하나를 만납니다. 결과는 재미로 보는 이야기이며 성격을 진단하지 않습니다.

## 실행

정적 파일 서버에서 `index.html`을 열면 됩니다. 예를 들어 Python이 있다면 `python -m http.server 8000`을 실행하고 `http://localhost:8000`에 접속하세요. ES 모듈을 사용하므로 파일을 직접 열기보다는 서버에서 실행하세요.

## 확인

`npm test`로 문항·유형 연결을 검사합니다. 별도의 패키지 설치는 필요하지 않습니다.

## 공유와 개인정보

결과 URL은 `?type=ENFP`처럼 유형만 담습니다. 답변과 사용자 정보는 서버나 브라우저 저장소에 기록하지 않습니다. 카카오 전용 버튼은 [카카오 JavaScript SDK](https://developers.kakao.com/docs/ko/kakaotalk-share/js-link)의 기본 텍스트 템플릿을 사용하며 서비스의 카카오 로그인 기능은 필요하지 않습니다. 배포 도메인을 카카오디벨로퍼스 앱의 JavaScript SDK 도메인 및 제품 링크 웹 도메인에 등록해야 작동합니다. 결과 링크 복사는 카카오 설정과 관계없이 사용할 수 있습니다.
